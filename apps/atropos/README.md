## Setup

Make sure to install dependencies:

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:4000`:

```bash
pnpm dev
```

ps. this is Nuxt SSR application, look at the [Nuxt documentation](https://nuxt.com/docs/4.x) to learn more.
